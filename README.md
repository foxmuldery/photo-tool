# 老y照片边框生成器

给照片加一圈干净的白边，配一句备注。纯前端、零依赖、不上传照片，打开网页就能用。

> 线上地址：<https://tool.foxlaoy.com/>　·　单文件应用：`index.html`

## 这个版本做了什么

v2.0 在 v1.3 的基础上做了一次完整重写：修掉了导出尺寸与预览不一致、批量导出 MIME 类型错误、重复函数覆盖、图片二次编码等一批问题，并把排版、批量下载和手机端体验补齐。

### 边框

- 0–30% 连续可调，保留「无 / 窄 / 中 / 宽」四个快捷档位
- 底色：白、米白、黑、浅灰，或任意自定义颜色
- 选择深色底时自动切换浅色文字，不会出现黑底黑字
- 可选图片外沿细描边（按图片尺寸等比缩放，不会在高分辨率下消失）

### 文字

- 支持多行、自动换行，中英文按各自规则断行
- 5 种字体：霞鹜文楷、思源黑体、思源宋体、长仓体、马善政楷书
- 字号、左中右对齐、加粗、文字颜色
- 文字可放在图片下方或上方
- 所有尺寸按图片宽度等比计算，**预览看到的比例就是导出的比例**

### 导出

- JPG（画质 70–100 可调）或 PNG
- 尺寸：原图 / 最长边 4000 / 3000 / 2000 / 1600 px
- 文件名后缀可自定义（默认 `_y`）
- 批量导出自动打包成 ZIP（内置 ZIP 写入，无第三方库）
- 导出时显示预计输出尺寸，按需解码原图，导完立即释放内存
- 大图与 iOS Safari 会自动降到安全画布尺寸，避免空白图

### 使用体验

- 拖拽、点击、`⌘V` 粘贴，一次可加多张
- 缩略图切换、单张移除、左右方向键翻页
- 设置自动记住（文字内容不保存，刷新后不残留上一张的备注）
- 跟随系统的深色模式
- 手机端底部固定操作栏、可点到的删除按钮、16px 输入字号（避免 iOS 自动放大）
- 键盘快捷键、可见焦点、`aria` 标签、支持缩放的 viewport

## 使用

直接双击 `index.html` 即可离线使用。也可以放到任意静态托管（GitHub Pages、Cloudflare Pages、Nginx）——不需要构建、没有后端。

### 快捷键

| 按键 | 功能 |
| --- | --- |
| `←` / `→` | 上一张 / 下一张 |
| `⌘S` / `Ctrl+S` | 导出当前照片 |
| `Delete` / `Backspace` | 移除当前照片 |
| `⌘V` / `Ctrl+V` | 粘贴剪贴板里的图片 |

## 关于字体

字体按需加载，不阻塞首屏：只有选中某个字体时才会去请求它。请求顺序是多个 CDN 依次回退（霞鹜文楷走 eleme / jsDelivr / unpkg，其余走 Google Fonts / 国内镜像 / fontsource）。

- 字体加载成功：画布用它渲染，状态栏显示「字体已就绪」
- 加载失败：自动回退到系统字体，状态栏会提示，**不影响导出功能**
- 想完全离线使用：把需要的字体文件下载到本地，用 `@font-face` 指过去即可

## 隐私

照片只在浏览器内存和 Canvas 里处理，不会上传到任何服务器，也没有统计脚本。页面唯一的外部请求是字体文件（不含任何照片数据）。断网时除字体外全部功能可用。

## 浏览器支持

Chrome / Edge / Safari / Firefox 的近两年版本，以及 iOS Safari、Android Chrome。依赖 `Canvas 2D`、`Blob`、`createImageBitmap`（不支持时自动降级为 `<img>` 解码）。

## 更新日志

### v2.0

**修复**

- 删除重复定义的 `downloadAll`（旧版后一个函数覆盖前一个，导致导出格式与文件名不一致）
- 修复 `toDataURL('image/jpg')` 的非法 MIME：旧版实际可能导出 PNG 却命名为 `.jpg`
- 修复字号固定 px 导致的「预览与导出不一致」：现在统一按图片宽度等比缩放
- 修复文字紧贴图片、底部留白翻倍的问题，重新计算文字区与上下留白
- 修复长文本不换行、超出画布被裁切的问题
- 修复上传时把每张照片重新编码成 PNG data URL 的性能与内存问题
- 修复批量导出多次触发浏览器下载拦截的问题（改为 ZIP）
- 修复缩略图长期持有原图导致的内存占用问题

**体验**

- 全新的响应式界面，桌面双栏 / 手机单栏，跟随系统深色模式
- 拖拽、粘贴、多选、缩略图移除、方向键与快捷键
- 底色 / 字色 / 对齐 / 上下位置 / 加粗 / 画质 / 尺寸 / 后缀
- 设置持久化、预计输出尺寸、导出进度与取消

**性能**

- 预览只保留最长边 1600px 的副本，导出时才解码原图，用完释放
- 输入防抖 + 按设备像素比渲染
- 字体按需加载，不再在首屏阻塞等待 5 个字体
- 导出改用 `canvas.toBlob`，不再生成体积巨大的 base64 字符串

### v1.3

- 优化移动端界面
- 修复边框宽度选项
- 优化代码结构

### v1.2
